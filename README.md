# Tema 
* E-Commerce: Serviço de Catalogo + Serviço de Pedidos + Pagamento;
* Caso Hipotético: Uma concessionaria procura programadores para criar uma conexão entre seus serviços no seu site de comercio;
* Linguagem de Programação: Python
* Objetivo: Criar o Middleware entre as redes para a comunicação rápida, eficiente e completa entre seus serviços

# Middleware_Distribuido__Projeto2_Arquitetura
Implementação de um middleware distribuido que conecte pelo menos 2 serviços a uma aplicação de domínio livre. Os serviços podem (devem) ser simplificados, porém a comunicação entre eles deve ser funcional e pratica (Utilize Python, Java ou Go)
